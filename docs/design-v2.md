# polka — новый рабочий интерфейс (закрытый пилот)

Новая визуальная система по предоставленному Raycast-референсу: почти чёрный фон, нейтральные кнопки, тонкие границы и внутренние блики, стеклянная навигация. В шапке используется присланный логотип polka. Системные шрифты работают без внешних запросов и дополнительных загрузок.

## Доступ и сохранение классической версии

- `/api/session` разрешает пилот только аккаунту `artem`, который проходит существующую проверку владельца. Проверяется закреплённый ID владельца, а не только имя.
- Обычные пользователи продолжают видеть классический рабочий интерфейс. Публичный лендинг обновлён для всех. Принудительное значение localStorage не даёт доступ к пилоту.
- У владельца при первом входе включается новый интерфейс. Переключатель **Классика / Новый** расположен вверху, в том числе на телефоне.
- Выбор сохраняется в текущем браузере отдельно для аккаунта. Данные, файлы, понятия и диалоги общие для обеих версий. Миграция не требуется.
- Старые компоненты и CSS сохранены. Новый слой находится в `app/design-v2.css` и `components/design-v2/workspace.tsx`. При отсутствии конфигурации владельца пилот закрыт.

## Что изменилось

Новый обзор с настоящими показателями библиотеки, продолжением изучения и быстрыми действиями. Единая визуальная система для материалов, предметов, знаний, практики, чата и аккаунта. `polka.id` показывает действительный идентификатор аккаунта. Командный поиск (⌘K / Ctrl+K) ищет разделы, заголовки материалов и понятия; по понятию открывает его источник. Публичный лендинг доступен владельцу через **О polka** или командный поиск.

Мобильная навигация учитывает safe area; формы используют размер текста 16px, чтобы избежать увеличения при вводе на iPhone. Предусмотрены видимый клавиатурный фокус, Escape и нативное удержание фокуса в модальных окнах. Уменьшенное движение учитывает настройки системы. Видео и тяжёлые анимационные библиотеки для нового оформления не добавлены.

## Проверка

```sh
pnpm typecheck
node --import tsx --test tests/*.test.ts
pnpm build
POLKA_TEST_PRODUCTION=1 pnpm test:design-browser
```

Браузерный тест требует установленный Google Chrome. Запускает отдельный сервер на localhost:3110, создаёт временные синтетические аккаунты и библиотеку, затем удаляет их. Не использует настоящие API-ключи и закрытое хранилище. Для локального HTTP в отдельном тестовом браузере снимается Secure-флаг с синтетической cookie; production-код продолжает устанавливать Secure. Порт можно изменить через `POLKA_TEST_PORT`. Скриншоты сохраняются в `/private/tmp/polka-v2-screens` или `POLKA_TEST_SCREENSHOTS`.

Проверяются ограничения пилота, сохранение выбранной версии, поиск, пакетный импорт понятий со ссылками, самопроверка, добавление текста на мобильной ширине, редактирование источника, отмена и подтверждение удаления, аккаунт, все основные разделы и диалоги на ширинах 320/390/768/1440. Ошибки отправки чата, остановка, индикатор ожидания, события SSE и переход по цитате проверяются с явно заданными тестовыми ответами ИИ. Реальный провайдер ИИ в этом тесте не вызывается.

Проверка размеров в Chromium не заменяет тест на физическом iPhone: системная клавиатура, установка PWA и особенности Safari требуют отдельной проверки на устройстве.
