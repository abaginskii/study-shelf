# polka: бренд, публичный лендинг и Telegram

Название продукта — `polka`. `public/brand/polka-wordmark.png` — присланное пользователем изображение без изменений. `BrandWordmark` отображает его через SVG viewport, исключающий окружающий холст; светлая и тёмная поверхности поддерживаются blend modes. Значки PWA, Apple и favicon пока прежние: пользователь пришлёт отдельный файл для них.

## Публичный лендинг

`components/marketing/polka-landing.tsx` и CSS module: тёмный первый экран, крупная типографика, светлое интерактивное демо, объяснение процесса, источник ответа, действующий тариф из `lib/plans.ts`, Telegram и юридические ссылки. Демо подписано как демонстрационное: вкладки, поиск и ответы работают локально, не создают материалы и не вызывают ИИ. CTA регистрации и входа открывают настоящие формы приложения.

Новый лендинг видят все посетители без авторизации. В рабочем интерфейсе пилот остаётся ограничен владельцем; переключатель называется **Классика / Новый**, поиск и существующие данные сохранены. Старый публичный лендинг остаётся в истории Git.

## Приглашение в Telegram

`TelegramPromo` монтируется в корневом layout. Ненавязчивая карточка появляется через 12 секунд на главной и `/pricing` для посетителей и всех аккаунтов. Она не захватывает фокус. При вводе текста, открытом диалоге, чате или самопроверке показ откладывается; оплата, админка и юридические страницы исключены. На телефоне карточка расположена над нижней навигацией с учётом safe area.

Закрытие или переход по ссылке `https://t.me/polka_it` скрывает приглашение на 30 дней в данном браузере (`polka.community.telegram.v1`). Без localStorage закрытие сохраняется до конца текущего открытия приложения. У ссылки `noopener noreferrer`; внешние Telegram-скрипты и аналитика не добавлены.

## Проверка

Основной изолированный browser runner подключает `landing-brand.cjs` и `telegram-promo.cjs`. Проверяются формы входа, демо-вкладки, поиск, самопроверка, клавиатура, переполнение на 320/390/768/1440, показ карточки для гостя/обычного аккаунта/владельца, задержка, закрытие и сохранение выбора, недоступное хранилище браузера, исключённые страницы и мобильные кнопки. Остальные проверки рабочего интерфейса используют настоящие локальные API и синтетическую библиотеку; ответы ИИ явно подменяются только для проверки UI.

Команды: `pnpm typecheck`, `node --import tsx --test tests/*.test.ts`, `pnpm build`, `POLKA_TEST_PRODUCTION=1 pnpm test:design-browser`. Облачные данные, реальные платежи и API нейросети в этих тестах не используются. Проверка Chromium не заменяет физическое устройство Safari/PWA.
