# polka — рабочее пространство

Единый новый интерфейс доступен всем авторизованным пользователям. Почти чёрные поверхности, тонкие границы, спокойные синие акценты и системные шрифты без внешних загрузок. Публичный лендинг остаётся доступен посетителям без аккаунта.

## Выпуск для всех

- Ограничение оформления аккаунтом владельца удалено. Для выбора нового интерфейса не нужны localStorage или отдельное разрешение.
- Переключатель **Классика / Новый** и компоненты классического оформления удалены из текущей сборки. Предыдущие версии сохранены в истории Git.
- Аккаунты, файлы, материалы, понятия и диалоги продолжают использовать существующие API и хранилище. Миграция данных не требуется.
- Панель `/admin` остаётся отдельной защищённой функцией. Доступ к новому интерфейсу не предоставляет доступ к пользователям или чужим библиотекам.

## Структура

`components/workspace/workspace.tsx` и `workspace.module.css` содержат навигацию, обзор библиотеки и командный поиск. `app/workspace.css` задаёт общую визуальную систему функциональных страниц: материалы, предметы, знания, практика, чат и аккаунт. `app/globals.css` сохраняет базовые формы, диалоги, карточки материалов и адаптивную структуру.

На компьютере шириной более 1024 px слева закреплена боковая панель шириной 232 px. В ней обзор, материалы, предметы, знания, практика, polka.ai, информация о сервисе, помощь и polka.id. В верхней полосе находятся поиск, добавление материала и аккаунт.

На ширине до 1024 px включаются компактная верхняя панель и нижняя навигация. Все разделы доступны также через мобильное меню. Оно закрывается после перехода, при нажатии снаружи и по Escape. Размеры кнопок учитывают касания; нижняя панель учитывает safe area.

## Главная и поиск

Обзор приветствует пользователя и показывает реальные показатели его библиотеки: материалы, готовые конспекты, понятия и повторения. В карточке продолжения открывается последний обновлённый готовый материал, а при отсутствии конспектов — последний обновлённый материал. Список недавних материалов, предметы и очередь разбора используют те же данные. При загрузке показывается состояние ожидания, при пустой библиотеке — предложение добавить первый материал. Счётчики активности и достижения не выдумываются.

Командный поиск открывается кнопкой или ⌘K / Ctrl+K. Он ищет разделы, заголовки материалов и понятия; по понятию открывает его источник. Стрелки выбирают результат, Enter открывает его, Escape закрывает окно. `polka.id` показывает действительный идентификатор аккаунта и позволяет его скопировать.

Значки PWA, Apple и favicon используют новый присланный знак из `public/icons/`. Логотип с названием отображается через `BrandWordmark`. Сервис не загружает внешний шрифт, видео или тяжёлую графическую библиотеку ради рабочего интерфейса. Анимации учитывают настройку уменьшенного движения.

## Проверка

```sh
pnpm typecheck
node --import tsx --test tests/*.test.ts
pnpm build
POLKA_TEST_PRODUCTION=1 pnpm test:design-browser
```

Имя browser script сохранено для совместимости; он проверяет текущий общий интерфейс. Требуется установленный Google Chrome. Runner запускает отдельный сервер на localhost:3110, создаёт временные синтетические аккаунты и библиотеку, затем удаляет их. Облачные данные, реальные платежи и API-ключи нейросети не используются. Для локального HTTP в отдельном тестовом браузере снимается Secure-флаг с синтетической cookie; production-код продолжает устанавливать Secure. Порт меняется через `POLKA_TEST_PORT`, папка скриншотов — через `POLKA_TEST_SCREENSHOTS`.

Проверяются доступ обычного пользователя и владельца к одному интерфейсу, отсутствие переключателя, поиск, импорт понятий со ссылками, самопроверка, добавление и редактирование текста, отмена и подтверждение удаления, аккаунт и все основные разделы на мобильных и компьютерных ширинах. Ошибки отправки чата, остановка, индикатор ожидания, события SSE и переход по цитате проверяются с явно заданными тестовыми ответами ИИ. Защита административных API проверяется независимо от оформления.

Chromium-проверка размеров не заменяет физический iPhone: системная клавиатура, установка PWA и особенности Safari требуют проверки на устройстве. Уже установленная PWA может сохранять прежний значок до обновления системного кэша или повторного добавления на домашний экран.

## Откат

Для возврата к предыдущему оформлению используется история Git, `git revert` соответствующего релиза и обычный деплой. Переключение на прежнее оформление внутри текущего приложения удалено. Визуальный откат не требует удаления пользовательских данных.
