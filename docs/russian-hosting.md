# Перенос на российское размещение

Проверено 6 октября 2026 года. Требования владельца: реальные продажи, серверы и данные в России, бюджет хостинга **0 ₽**. Новый хостинг не создан, данные не перенесены, реальные платежи выключены.

## Что подготовлено в коде

- `POLKA_STANDALONE=true` включает отдельную серверную сборку Next вне Vercel. На Vercel этот флаг не меняет формат сборки.
- `Dockerfile` собирает приложение с Node 22 и pnpm 11.19.0; runtime работает от пользователя без root.
- `.dockerignore` исключает секреты, локальные данные, Git и служебные каталоги из контекста сборки.
- Cookie входа получает Secure в production вне Vercel.

Сборка и запуск standalone проверены на локальном Node 24.19 с синтетическими данными: регистрация, сессия, защищённая API владельца и статические ресурсы. Linux Docker-образ не проверен: Docker на рабочей машине отсутствует.

Это подготовка runtime. Текущий storage остаётся Vercel Blob; загрузка файлов более 4 МБ использует его клиентский SDK. Развёртывание одного Docker-образа не переносит аккаунты, лекции, платежи и хранилище. `LOCAL_DATA_DIR` нельзя использовать на эфемерном диске или с несколькими процессами: файловая блокировка действует внутри одного процесса. Перенос требует постоянного хранилища с атомарными условными записями, переноса больших загрузок и проверки изоляции пользователей.

## Результат проверки хостинга

| Вариант | Что бесплатно | Что мешает полному запуску за 0 ₽ |
| --- | --- | --- |
| Layero Free | Next runtime, HTTPS, адрес платформы | Постоянная БД платная, диск runtime эфемерный; внешний storage нужен отдельно |
| Cloud.ru Free VM | Старым подходящим аккаунтам: ВМ и загрузочный диск | Новым аккаунтам после 30 июня 2026 недоступна; публичный IP или SNAT оплачиваются отдельно |
| Облачные free tier | Ограниченные объёмы операций и хранения | Превышение оплачивается; это не гарантия нулевого счёта публичного приложения |
| Netlify Free | Коммерческие проекты в пределах квоты | Зарубежное размещение не соответствует выбранному требованию |

На дату проверки полного подходящего размещения с постоянными данными и гарантированным бюджетом 0 ₽ не найдено. Пробные бонусы и платные услуги нельзя представлять как бесплатный постоянный хостинг. Покупка тарифа не разрешена владельцем.

## Условие о данных в России

Текущая production-база находится в Frankfurt Blob, материалы для обработки отправляются Google Gemini. Эти подключения не соответствуют новому требованию «серверы и данные строго в России». Перед реальными продажами требуется выбрать российское хранилище и обработчик ИИ, перенести и сверить существующие данные, обновить описание фактической обработки и проверить оплату в тестовом магазине ЮKassa. До проверки оформления покупки не включать.
