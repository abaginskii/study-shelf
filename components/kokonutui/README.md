# Kokonut UI adaptations

The prompt layout and auto-resizing textarea algorithm are adapted from the official `ai-prompt` registry component. The rotating text loading indicator is adapted from `ai-text-loading`.

- https://kokonutui.com/r/ai-prompt.json
- https://kokonutui.com/r/ai-text-loading.json
- https://github.com/kokonut-labs/kokonutui

Copyright © 2025 kokonutUI. MIT license: [LICENSE](./LICENSE).

Adaptations use local CSS instead of Tailwind and Motion to keep the application small. Model selection, promotional banners and nonfunctional attachment controls from the demo were removed. Submission is connected to the application chat API; reduced motion and keyboard/IME behavior are supported.
