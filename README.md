# Полка

[Открыть приложение](https://study-shelf-three.vercel.app)

Общее учебное приложение: загрузите лекцию, получите конспект, соберите базу понятий и проверьте себя. Каждый пользователь создаёт собственный аккаунт и видит только свои материалы. Приложение самостоятельно, учебные репозитории к нему не подключены.

## Возможности

- Регистрация по логину и паролю, вход, выход и одноразовый код восстановления.
- Фото, PDF, аудио, видео, TXT и Markdown; оригинал сохраняется до обработки.
- Извлечение текстового слоя PDF, распознавание фото и сканов, расшифровка аудио.
- Конспекты, понятия и вопросы по источнику через Google Gemini с собственным API-ключом.
- Потоковый чат с Gemini: контекст разговора, закрытая история, ссылки на источники, остановка и повтор ответа.
- Предметы, поиск, проверенные понятия, повторение и экспорт заметок в JSON.
- Адаптивный интерфейс, клавиатурная навигация и добавление на домашний экран.

## Запуск

Node.js 22+ и pnpm 11:

```sh
pnpm install
cp .env.example .env.local
# Укажите случайный AUTH_SECRET (минимум 32 символа).
pnpm dev
```

Для локальной разработки используется `LOCAL_DATA_DIR`. На Vercel этот режим всегда отключён; данные должны храниться в закрытом Vercel Blob.

## Vercel

1. Импортируйте репозиторий как Next.js проект.
2. Создайте **Private** Vercel Blob и подключите к проекту. SDK использует `BLOB_STORE_ID` с автоматическим OIDC либо `BLOB_READ_WRITE_TOKEN`.
3. Задайте `AUTH_SECRET` случайной строкой минимум 32 байта. Секреты не публикуйте в Git.
4. Добавьте `GOOGLE_GENERATIVE_AI_API_KEY` по инструкции ниже. `AI_GATEWAY_DISABLED=true` исключает автоматическое подключение платного Vercel AI Gateway.
5. Запустите деплой. Код не записывает пользовательские данные на диск серверной функции.

Локальное хранилище и production хранилище независимы. Экспорт JSON включает заметки, тесты и понятия; исходные файлы скачиваются отдельно.

## Подключение Google Gemini

Создайте ключ в [Google AI Studio](https://aistudio.google.com/apikey). В настройках проекта Vercel → **Environment Variables** добавьте `GOOGLE_GENERATIVE_AI_API_KEY` для Production, затем выполните новый деплой. Для локального запуска добавьте ключ в `.env.local`. Ключ хранится на сервере и не передаётся в браузер; не используйте для него префикс `NEXT_PUBLIC_`.

Модель по умолчанию — `gemini-3.1-flash-lite`; её можно изменить через `AI_MODEL`. Gemini напрямую обрабатывает конспекты, изображения, PDF и аудиозаписи. Для крупных файлов используется Google Files API; временная копия удаляется после обработки, а при невозможности удаления Google удаляет её автоматически через 48 часов. Оригинал остаётся в закрытом хранилище приложения.

Оставьте `AI_GATEWAY_DISABLED=true`: собственный ключ Gemini работает независимо от этого флага. Если Gemini не подключён, приложение сохраняет материалы и сообщает о недоступности ИИ. Дополнительный вариант — выключить этот флаг и настроить AI Gateway; автоматического переключения с ошибкой Gemini на платный Gateway нет.

Проверьте доступные квоты проекта в Google AI Studio. Приложение ограничивает пользователя 15 запросами ИИ в день и все аккаунты суммарно 200 запросами в день; общий предел настраивается через `AI_DAILY_LIMIT`. Ограничения Google действуют дополнительно. [Модель и поддерживаемые входные форматы](https://ai.google.dev/gemini-api/docs/models/gemini-3.1-flash-lite), [работа с API-ключами](https://ai.google.dev/gemini-api/docs/api-key).

## Пределы текущей версии

100 материалов, 200 понятий, 300 МБ сохранённых файлов на аккаунт; файл до 60 МБ, распознавание до 20 МБ, текст до 120 000 символов. Один AI-конспект принимает до 45 000 символов. Лимит — 15 AI запросов в день. Длинные лекции нужно разделить. Для видео поддержан просмотр оригинала; для расшифровки загрузите аудиодорожку отдельно. Код восстановления нужно сохранить: электронная почта при регистрации не используется.

AI ответы требуют проверки по оригиналу. Распознавание и генерация отправляют выбранный материал Google Gemini либо явно подключённому AI Gateway. Ошибка AI не удаляет оригинал. Закрытый Blob хранит документы пользователей и библиотечный индекс с проверкой версий; для больших каталогов следующая ступень масштабирования — перенос индекса в Postgres.


## Документы и будущая подписка

Чаты доступны по личной ссылке `/?chat=<id>` после входа в свой аккаунт и включаются в экспорт библиотеки. До 30 диалогов и 20 вопросов в каждом; при достижении лимита нужно начать новый диалог, предыдущая история сохраняется. Для ответа модель получает ограниченный контекст последних сообщений и релевантные фрагменты источников.

В записи JSON из Blob запрашивается несжатая версия, чтобы ETag чтения совпадал с условной записью. Это устраняет ложный «Конфликт изменений» для длинных PDF/текстов. Настоящее изменение исходного текста во время ИИ-обработки по-прежнему отклоняет сохранение устаревшего результата.

Публичные страницы: `/offer`, `/privacy`, `/payment`. Сейчас доступ бесплатный; заказов, карт и списаний нет. Расширенная подписка анонсирует увеличенные лимиты библиотеки, хранилища и ИИ. Стоимость, период и дату запуска нужно определить перед подключением платежей. Поддержка: polka_service@ya.ru.

Перед платным запуском нужны платные условия, приём оплаты, выдача чеков НПД, порядок отмены и возвратов. Текущее хранилище в Frankfurt не подтверждает выполнение требований РФ о локализации данных: потребуется отдельно подготовить размещение данных российских пользователей и трансграничную обработку. Публикация политики эту задачу не решает.

Gemini API имеет ограничения возраста и доступных регионов; приложение рассчитано на взрослых пользователей. Не отправляйте личные или конфиденциальные данные. В бесплатном режиме Google может использовать материалы для улучшения продуктов. Перед коммерческим запуском проверьте тариф, допустимые регионы аудитории и условия выбранного AI-провайдера.

Источники: [ФНС о чеках самозанятых](https://www.nalog.gov.ru/rn40/news/tax_doc_news/16645245/), [23-ФЗ о персональных данных](https://publication.pravo.gov.ru/document/0001202502280034), [Gemini API Terms](https://ai.google.dev/gemini-api/terms).
