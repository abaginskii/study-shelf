# Полка

Личное учебное веб-приложение для телефона и компьютера. Хранит оригиналы материалов, распознанный текст, конспекты, вопросы и проверенные заметки в базе знаний. Проект полностью отдельный от `second_brain`.

## Возможности

- Загрузка фото, PDF, аудио, видео, Markdown, TXT и вставка текста.
- Извлечение текста из обычных PDF и текстовых файлов. Фото и аудио обрабатываются при наличии `OPENAI_API_KEY`.
- Редактирование распознанного текста, конспект и вопросы по материалу, поиск по содержимому.
- Проверенные понятия добавляются в базу знаний вручную со ссылкой на материал.
- Адаптивный интерфейс и установка на домашний экран как веб-приложения.

Видео сохраняется как оригинал; для расшифровки пока нужно загрузить аудиодорожку. Сканированные PDF без текстового слоя пока не распознаются автоматически. Без API-ключа приложение создаёт простой конспект из первых абзацев и вопросы из предложений источника.

## Локальный запуск

```bash
python3 -m pip install -r requirements.txt
python3 server.py
```

Откройте <http://127.0.0.1:8080>. База и файлы создаются в `data/`; каталог исключён из Git. Для локального доступа на этом компьютере пароль необязателен.

## Размещение на российском сервере

Рекомендуемый вариант для текущей версии — VPS в Timeweb Cloud с постоянным диском. Сервис App Platform пересоздаёт контейнер при деплое, поэтому локальные SQLite и загруженные файлы там будут потеряны без внешних БД и файлового хранилища. Настоящий сервер с `compose.yaml` сохраняет их в `./data`.

1. Скопируйте репозиторий на VPS с Docker и Docker Compose.
2. Создайте `.env` на основе `.env.example`. Задайте длинный `APP_PASSWORD` и случайный `APP_SECRET`; `OPENAI_API_KEY` добавьте при желании. Не отправляйте `.env` в Git.
3. Запустите `docker compose up -d --build`.
4. Настройте HTTPS reverse proxy (например, Caddy) на `127.0.0.1:8080` и домен. Не открывайте порт приложения напрямую в интернет.
5. Сохраняйте резервные копии каталога `data/`. В нём содержатся исходные файлы и база.

На сервере `APP_PASSWORD` и `APP_SECRET` обязательны. Работа ИИ отправляет содержимое выбранного материала в OpenAI API; использование этой возможности зависит от доступности API и вашего ключа.

## Данные и исходное хранилище

Этот репозиторий содержит только код. Он не копирует и не меняет `second_brain`, не содержит материалов из `raw/` и не синхронизируется со старым GitHub. Если позднее понадобится импорт, его следует делать отдельно с проверкой прав на материалы.
